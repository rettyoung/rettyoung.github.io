Privacy policy

Effective October 22, 2026.

Market Health Monitor is a personal tool used only by its owner. It requests one Google permission, drive.file, which lets it see and edit only the Google Drive files it creates itself. It cannot read any other file in the user’s Drive.

It uses that access only to create and update its own files (a tracker workbook, data files and dated snapshots) in a folder in the owner’s Drive. It does not collect, sell, share or transfer Google user data to anyone, does not use it for advertising, and does not use it to train AI models.

The access token is stored as an encrypted secret in the owner’s private repository and can be revoked at any time at myaccount.google.com/permissions.

Market Health Monitor’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue at github.com/rettyoung/rettyoung.github.io.
